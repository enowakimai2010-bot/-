# 忘れ物ナビ｜画像認識AI接続版

## この版でできること
- 生徒ページでは「返却済みにする／取り消す」操作を表示しない。
- 返却状態の変更は先生ロールのときだけUIに表示・実行する。
- 「忘れ物を登録」「なくした物を申請」で写真を選び、AI分析ボタンを押すと、画像そのものをAIが見てカテゴリー・物の名前・色・ブランド・柄・特徴の候補を入力する。
- AIのAPIキーはブラウザに置かず、Netlify Functionの環境変数 `OPENAI_API_KEY` に設定する。
- API未設定時は、これまでのファイル名ベースの簡易候補入力に自動フォールバックする。

## AI接続の仕組み
ブラウザ → `/api/analyze-image` → Netlify Function → OpenAI Responses API → JSON → ブラウザ

OpenAIのResponses APIを使う構成です。新規の統合ではResponses APIが推奨されています。

## 公開時の設定
1. Netlifyでこのフォルダをデプロイ。
2. Netlifyのサイト設定で環境変数を追加。
   - Key: `OPENAI_API_KEY`
   - Value: 自分で用意したOpenAI APIキー
3. 再デプロイ。
4. 「忘れ物を登録」または「なくした物を申請」で写真を選び、「写真を分析して入力」を押す。

**APIキーを `index.html` に書いたり、GitHubへコミットしたりしないでください。**

## 注意
- AIの判定は候補入力なので、登録前に人が内容を確認してください。
- 学校で使う場合は、先生・学校のルールを確認し、顔や名前など不要な個人情報が写った写真は使わない設計がおすすめです。
- OpenAI APIの利用には料金が発生する場合があります。学校プロジェクトなら、APIアカウント・支払いは先生や保護者など責任を持てる大人と確認して設定してください。
